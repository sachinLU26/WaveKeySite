Why it matters

From sign-in certainty to session certainty.

NIST emphasizes explicit authentication intent and allows long session windows. WaveKey pairs one explicit start action with continuous presence verification through the session window to reduce exposure without repeated prompts.

  1. 01 User starts the session with one deliberate action
  2. 02 Endpoint verifies ongoing authorized presence signals
  3. 03 Session is terminated when presence is lost
